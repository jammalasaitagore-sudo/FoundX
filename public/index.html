Phase 1 - API online

FoundX

Campus Lost and Found Portal - Express REST API with Supabase (Postgres, Auth, Storage).

The full interface is built in Phase 4. Until then, use these endpoints:

  • GET /api/health - service and database status
  • GET /api - endpoint index
  • GET /api/items - browse listings
  • GET /api/meta/categories - categories

Try a filter: /api/items?type=found&building=Central%20Library&sort=newest
